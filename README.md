Personal Project Showcase

A simple React application to add, view, and search your personal projects. Built with Vite.

Features

- Add new projects with title and description
- Search projects by title
- Projects are saved automatically in the browser (localStorage)
- Clean and responsive design

Default Projects
- E-commerce Website
- Weather Dashboard  
- Todo App

Tech Stack

- React 18
- Vite
- JavaScript (JSX)
- CSS
